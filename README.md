## 先明确一件事：Windows 开服和"房主开房间"不是一回事

《幻兽帕鲁》官方的多人模式有两种：

- **合作模式**：由一个玩家做主机，最多 4 人，主机下线世界就停。

搜 Windows 开服的人要的是后者。它的好处很直白：机器不关机，服就一直在；配置不够时升内存升 CPU 就行，不用换电脑。代价是得自己管服务端，包括更新、配置、定期重启。

## 开服前必须确认的三个硬指标

官方服务器文档给出的要求如下：

| 项目 | 要求 |
| --- | --- |
| CPU | 4 核（推荐） |
| 内存 | 16GB；稳定运行建议 32GB 以上 |
| 存储 | 强烈建议 SSD，低速存储有损坏存档的风险 |
| 网络 | 需要能放行 UDP 8211（默认端口，可改） |
| 系统 | Windows 64 位 / Linux 64 位 |

内存这一项是最容易踩坑的。官方最低写 8GB 能启动，但同一份文档里也写明 8GB 会显著提高内存不足崩溃的概率。国内几家云厂商的搭建教程更直接，普遍建议至少 4 核 16GB 起步。

另一个常被忽略的点是**单核主频比核心数更管用**。帕鲁的 AI、据点自动化这类模拟任务偏单线程，一颗 4 核高频 CPU 在实际体感上往往好过一颗低频 8 核。这也是为什么游戏云这类"高主频机型"在开服场景里卖得比普通云服务器好。

## 从下单到进服：Windows VPS 完整流程

以 Windows VPS 为例，按这个顺序走基本不会卡住。

**第一步：购买时选对系统和预装**

系统选 Windows Server（雨云教程里用的是 2019，也可以选更新的版本），同时勾选帕鲁预装。计费模式分两种：

- **固定计费**：固定月租，不额外收费，适合每天都开。
- **动态计费**：低价月租 + 按每日 CPU 超额使用率日结「电费」，CPU 使用率基准值是 20%，低于 20% 不算耗电。适合想起来才玩两小时的人。

大概每天玩超过 2 小时，固定计费更划算。

**第二步：远程桌面连进去**

用 Windows 自带的远程桌面（RDP），输入控制台给的远程连接地址和端口。注意端口不一定是默认的 3389——如果买的是 NAT 模式（共享公网 IP），3389 会被映射到别的端口，控制台里写得很清楚。用户名默认是 Administrator。

**第三步：处理防火墙**

雨云的 Windows Server 2019 镜像默认是关闭防火墙的。如果你换过系统或者开着防火墙，记得放行帕鲁用的 UDP 8211；生产环境更稳妥的做法是只开需要的端口，而不是整个关掉。

**第四步：做端口映射**

买了独立公网 IP 的跳过这步。NAT 模式需要在控制台「NAT 端口映射」里新建规则，把内网端口 8211 映射出去。外网端口会自动生成，如果提示被占用就手动换一个，记下来——这个端口要填到游戏里。

**第五步：启动服务端**

预装了帕鲁的话，双击桌面的「启动幻兽帕鲁服务端.bat」，玩家通过 `你的IP:8211` 连接。想手动部署则用 SteamCMD：


steamcmd +login anonymous +app_update 2394010 validate +quit


`2394010` 就是帕鲁专用服务端的 Steam App ID。整个下载量大约 12-15GB，第一次装要等一会。顺带说一句，开服不需要自己有游戏——匿名登录就能拉服务端，只有连接的玩家需要买游戏。

**第六步：客户端连进来**

Steam 里启动帕鲁 → 加入多人游戏（专用服务器）→ 底部输入 `地址:端口` → 点「联系」。默认没有密码，设了密码的话在弹窗里输入。

## 配置文件：只改一个就够了

Windows 下的活动配置文件是：


C:\PalServer\Pal\Saved\Config\WindowsServer\PalWorldSettings.ini


这个文件初始是空的，需要把同目录下的 `DefaultPalWorldSettings.ini` 内容整个复制过去再改。**不要直接改默认文件**——改它不会影响服务器，这是新手最容易白忙一场的地方。

值得一改的参数不多：

- `ServerName` / `ServerPassword` / `AdminPassword`：服务器名、进服密码、管理员密码。开公网服不设密码，等于请陌生人进你家。
- `ServerPlayerMaxNum`：最大玩家数，默认 32，也是上限。
- `BaseCampWorkerMaxNum`：单个据点能安排多少只帕鲁干活，默认 15。这个值直接影响内存和 CPU 占用，调低到 10-12 能明显减压。
- `ExpRate`、`PalCaptureRate` 这类倍率：纯玩法选择，建议开服前定好，等世界跑起来再改容易出意外。

改完保存，重启服务端才生效。

## 两个一定会遇到的坑

**内存泄漏。** 帕鲁服务端有个长期存在、社区公认的内存泄漏问题：跑得越久，进程占的内存越多。标准解法是定时重启。Windows 下可以用任务计划程序挂一个每日重启任务，放在凌晨玩家最少的时候。

> 如果你打算 24 小时挂着，值班式的每日重启基本是必须做的。这不是可选项。

**版本不一致。** 报「你正尝试加入的比赛正在运行不兼容的游戏版本」，说明客户端更新了但服务端没更新。重启前先执行一次带 `validate` 的更新命令，服务端会拉到最新版本。

另外一条：**Xbox 和 Game Pass 版本没有完整的专用服务端**，只有 Steam 版本才能用来开服。走这条路之前先确认你和朋友玩的是哪个版本。

## 常见问题

**能不能用自己家里的电脑开服？**

技术上可以，实际瓶颈在公网和稳定性。家用宽带上行通常很小，玩家一多就跳 ping，而且电脑关机服就停。帕鲁服务端还要求 UDP 8211 能被公网访问，很多宽带做不了端口映射。这也是游戏云存在的原因。

**8G 内存真的不行吗？**

能启动，能玩。但官方文档自己就警告过 OOM 崩溃风险。4-6 人的小服配合每日重启实际能用，人数再多就建议 16G 起。

**Windows 还是 Linux？**

只开帕鲁、不装 MOD，Linux 服务端资源占用更低。要装 MOD 就必须 Windows——目前模组只支持 Windows 系统。这也是很多人搜「幻兽帕鲁Windows开服」的原因。

**服务端要装多久？**

首次通过 SteamCMD 拉 `2394010`，大概 12-15GB，国内网络环境通常十几分钟到半小时。之后更新只下差异部分，快得多。

**几个人玩要买多贵的？**

2-4 人的小型联机，进阶级（4 核 8G）配合固定计费够用；人数上双位数或者打算长期挂机，直接上 6 核 12G，省得中途升配搬存档。
